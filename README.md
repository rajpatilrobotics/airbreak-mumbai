# AirBreak Mumbai

A school-planning UI prototype inspired by the [Google Mumbai Data Challenge](https://zindi.world/competitions/google-mumbai-data-challenge). It explores how hourly PM2.5 forecasts could help Mumbai schools plan outdoor periods around class schedules, lunch breaks, and shared playground capacity.

## Prototype workflow

1. Enter school hours, breaks, and outdoor capacity.
2. Describe which classes need outdoor sessions and how long each session should last.
3. Review feasible time windows alongside an illustrative hourly PM2.5 chart.

The prototype demonstrates the planning workflow and how forecast uncertainty can be presented to a teacher. The charts use illustrative values. Live air-quality data integration and operational school use were outside this prototype’s verification scope.

## Project scope

This repository documents the product prototype. The Google Mumbai challenge entry is the separate forecasting research project, which covers data processing, time-based validation, and PM2.5 model evaluation.
